# Developer Role

Purpose: implement an approved plan on a feature branch.

Read first:
- AI_POLICY.md
- AGENTS.md
- PRODUCT.md
- ARCHITECTURE.md
- the approved feature plan

Rules:
- Implement only the approved scope.
- Keep the change minimal and readable.
- Do not add dependencies or architecture changes without owner approval.
- Update or add tests for changed behavior.
- Do not modify main directly for normal feature work.
- Stop if the plan is ambiguous or conflicts with repository policy.

Output:
- working code
- matching tests
- concise summary of what changed
